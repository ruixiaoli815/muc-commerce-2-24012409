## 用自己的话回答

- 什么是特征，什么是标签：特征：做判断时可以查看的信息，比如使用月数、是否投诉、登录设备。 标签：希望预测的答案。
- 为什么要保留测试集：样本训练后用测试集来验证训练效果，用样本测试效果不准确。
- 为什么83%准确率仍可能没有用：因为模型可能因误判导致准确率接近正确但是其中个体与准确答案差别较大。
